Gmail OTP Setup
Complete Guide

இந்த guide-ஐ follow பண்ணுங்க — உங்க portal-ல் interview எழுத வரும் எந்த candidate எந்த email-ல் signup பண்ணினாலும், அவங்க email-க்கே OTP தானா போகும்!

🔄 System எப்படி work ஆகுது — முதல்ல இதை புரிஞ்சுக்கோ
உங்க Gmail (Sender) ➡ App Password (One-time setup) ➡ Portal Server ➡ Candidate's Email-க்கு OTP
Example:
🔵 Candidate Ramesh → ramesh@gmail.com signup → OTP → ramesh@gmail.com-க்கு போகும்
🟣 Candidate Priya → priya@yahoo.com signup → OTP → priya@yahoo.com-க்கு போகும்
🟡 Candidate Kumar → kumar@outlook.com signup → OTP → kumar@outlook.com-க்கு போகும்

✅ நீங்க ஒரே ஒரு முறை App Password set பண்ணா போதும் — அதுவே எல்லாருக்கும் works!

5
Step 5 — Copy the Password
16-character App Password-ஐ Copy பண்ணுங்க
"Create" click பண்ணிட்டா Google ஒரு 16-character password show பண்ணும்:
abcd efgh ijkl mnop
← இது மாதிரி 4 groups-ஆ தெரியும் (spaces normal — ignore பண்ணலாம்)

இந்த password-ஐ Ctrl+C (Copy) பண்ணுங்க அல்லது "Copy" button click பண்ணுங்க.
⚠️ இந்த password popup ஒரு முறை மட்டுமே தெரியும்! Done பண்ணி close பண்ணிட்டா மறுபடியும் பார்க்க முடியாது. தப்பா copy ஆனா — மறுபடியும் Step 4 repeat பண்ணி new App Password create பண்ணுங்க.
6
Step 6 — Final Step!
கீழே உள்ள form-ல் Paste பண்ணுங்க → Save பண்ணுங்க ✅
Copy பண்ண App Password-ஐ கீழே உள்ள "Gmail App Password" field-ல் Paste பண்ணி "Test & Save" button click பண்ணுங்க.

✅ Save ஆனவுடன் — உங்க portal-ல் எந்த candidate signup பண்ணினாலும் அவங்க email-க்கு real OTP போகும்!
💡 "Test & Save" பண்ணினா உங்க own Gmail-க்கு ஒரு test OTP அனுப்பும் — inbox check பண்ணி confirm பண்ணலாம்.

⚙️ Step 6: Gmail SMTP Configure & Activate

Step 5-ல் copy பண்ண App Password-ஐ இங்கே paste பண்ணுங்க & save பண்ணுங்க.
